# امنیت

## اصول رعایت‌شده در این ریپو

1. **بدون Secret در سورس**
   - مترجم از APIهای رایگانِ بدون کلید استفاده می‌کند (MyMemory / LibreTranslate) — هیچ API key وجود ندارد.
   - هیچ توکن، پسورد یا کلید امضایی در کد، commit تاریخ یا فایل‌های تنظیمات وجود ندارد.

2. **Keystore امضا**
   - `key.properties` و `*.jks` / `*.keystore` در `.gitignore` هستند.
   - نسخه release فعلاً با debug key امضا می‌شود (قابل نصب برای تست)؛ برای انتشار تجاری طبق `docs/BUILD.md` عمل کنید.

3. **دسترسی‌های اندروید (کمینه)**
   - `INTERNET` — فقط برای مترجم آنلاین
   - `RECORD_AUDIO` — فقط برای دکمه میکروفن در مترجم (STT)
   - دیکشنری و کتابخانه کاملاً آفلاین‌اند و هیچ داده‌ای از دستگاه خارج نمی‌شود.

4. **داده کاربر**
   - تمام داده‌ها (علاقه‌مندی، پیشرفت، بوکمارک) فقط در Isar روی خود دستگاه ذخیره می‌شود.
   - هیچ analytics / tracker / ad SDK وجود ندارد.

## توصیه‌های عملیاتی

- توکن‌های GitHub را با حداقل scope لازم بسازید و بعد از استفاده **revoke** کنید؛ توکنی که در چت/اسکرین‌شات لو رفته را فوراً باطل کنید (Settings → Developer settings → Tokens).
- اگر Secretی به اشتباه commit شد، فقط حذف از HEAD کافی نیست — تاریخچه را بازنویسی کنید (`git filter-repo`) و کلید را بچرخانید.
- برای CI از Secrets رمزگذاری‌شده گیت‌هاب استفاده کنید، نه فایل داخل ریپو.
- Branch protection روی `main` را فعال کنید تا push مستقیم محدود شود (اختیاری برای پروژه شخصی).
